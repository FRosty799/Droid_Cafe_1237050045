## Application Flow

### 1. Splash Screen
* **Branding:** App Logo
* **Actions:** Sign In / Log In buttons

### 2. Authentication
* **Inputs:** Email & Password
* **Action:** Entry to the Menu

### 3. Menu
* **Display:** 3 Featured Food Items
* **Action:** Cart Button (Floating Action)

### 4. Checkout (Cart)
* **User Details:** Name, Address, City, Phone Number
* **Instructions:** Note/Special Request
* **Shipping:** Delivery Method Selection

### 5. Order Status
* **Confirmation:** Final order summary
* **Navigation:** Back to Home button
